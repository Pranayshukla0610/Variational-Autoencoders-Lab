# Variational-Autoencoders-Lab
A comprehensive repository focused on Variational Autoencoders (VAEs) and deep generative learning.  

This repository includes:
- VAE fundamentals and architecture
- Encoder–decoder implementations
- Latent space visualization
- Image generation and reconstruction
- KL Divergence and ELBO optimization
- CNN-based VAEs
- Conditional VAEs (CVAE)
- Advanced generative AI projects

## Tech Stack
- Python
- TensorFlow / PyTorch
- NumPy
- Matplotlib
- Scikit-learn

## Applications
- Image generation
- Anomaly detection
- Feature extraction
- Data compression
- Representation learning

## Goal
To provide beginner-to-advanced hands-on implementations of Variational Autoencoders for research, learning, and real-world AI applications.
